# 04 第 4 级：独立桌面

这一级做完，桌面上的程序是各自独立的进程。窗口、输入、剪贴板、文件选择、中文输入和浏览器都走明确的协议，一个程序出错不会带走桌面。

进入条件：[《多用户服务系统》](./03-services.md)的检查全部通过。

## 这一级要达到的行为

- 能做：多个独立 GUI 程序同时显示和操作，中文输入，剪贴板，拖放和文件选择，一个受隔离的浏览器访问真实网页。
- 必须失败得对：杀掉一个客户端不结束桌面，畸形的 IPC 和越界的共享缓冲被拒绝，恶意客户端读不到其他窗口和输入，渲染器读不到私有文件，资源超额不会终止桌面。
- 不能据此宣称：桌面进程里再画一个控件等于独立应用，无头渲染等于不用图形平台，关掉沙箱打开网页等于安全浏览。

## 任务

同一步里的任务可以按任意顺序做，后一步的任务一定用到前面步骤的成果。每项任务的名字后面括号里先写由谁实现，再写前置。前置是本文档里的任务时直接写名字，是别的文档里的任务时带上那份文档的名字。

### 第 1 步

- [ ] **稳定进程引用与回收**（内核机制、Linux 接口，前置[《可信命令行》](./01-shell.md)的「生命周期与退出取消」、[《可信命令行》](./01-shell.md)的「进程和管理操作鉴权」）：按需要提供 pidfd/子收割等不会误指向复用 PID 的管理能力。验收：服务退出和 PID 复用竞争中不误杀新进程，孤儿子孙最终被回收。
- [ ] **最小音频设备接口**（内核机制，前置[《多用户服务系统》](./03-services.md)的「设备模型接口封口」、[《可信命令行》](./01-shell.md)的「统一等待与取消约定」）：先选一个可测试 PCM 后端，定义缓冲、时钟、关闭和权限。验收：测试音可播放、停止可回收、坏缓冲不能访问内核内存，不在内核做混音 UI。
- [ ] **安全共享缓冲约定**（用户态组件、用户态库，前置[《原生开发工作站》](./02-workstation.md)的「memfd 与 POSIX 共享对象」、[《原生开发工作站》](./02-workstation.md)的「UNIX 套接字身份与名字」、[《可信命令行》](./01-shell.md)的「公共路径访问检查」）：定义版本、格式、尺寸上限、背压与 FD 寿命，使用禁止缩小的 seal 或等价固定尺寸方案，校验乘法溢出并快照提交元数据。验收：提交后缩小/关闭/重复提交、并发改头部均不能使合成器越界或崩溃，退出无页泄漏。
- [ ] **挂载命名空间**（内核机制、Linux 接口，前置[《原生开发工作站》](./02-workstation.md)的「通用挂载生命周期」、[《可信命令行》](./01-shell.md)的「进程和管理操作鉴权」）：分离挂载视图，提供正确的 unshare/setns 与命名空间句柄寿命。验收：一方挂卸载不改另一方，跨 namespace 路径/句柄不能绕过权限。
- [ ] **权限下降与 seccomp**（内核机制、Linux 接口，前置[《可信命令行》](./01-shell.md)的「明确 ABI 与公共模块边界」、[《可信命令行》](./01-shell.md)的「进程和管理操作鉴权」、[《可信命令行》](./01-shell.md)的「标准信号帧与备用栈」）：实现 no_new_privs 与所承诺的 seccomp-BPF 行为。验收：被禁止调用确实拒绝/终止，过滤跨线程/exec 的继承正确，未知能力不空成功。
- [ ] **基础运行时与 V8 探针**（用户态组件、用户态库，前置[《原生开发工作站》](./02-workstation.md)的「epoll 的完整目标语义」、[《原生开发工作站》](./02-workstation.md)的「memfd 与 POSIX 共享对象」、[《可信命令行》](./01-shell.md)的「标准信号帧与备用栈」、[《可信命令行》](./01-shell.md)的「ABI 行为清单逐组升级」）：验证工具链、线程、可执行映射与运行库。验收：诊断小程序通过，V8 成功不能当 Chromium 成功。

### 第 2 步

- [ ] **进程外窗口最小协议**（用户态组件、用户态库，前置「安全共享缓冲约定」、[《原生开发工作站》](./02-workstation.md)的「时钟与 timerfd」）：先完成创建、提交、输入、resize、关闭的一个闭环。验收：两个独立程序同时显示和输入，杀掉一个不结束另一个。
- [ ] **任务管理器**（用户态组件，前置[《原生开发工作站》](./02-workstation.md)的「procfs 进程视图」、[《多用户服务系统》](./03-services.md)的「应用/服务资源组」、「稳定进程引用与回收」、[《可信命令行》](./01-shell.md)的「进程和管理操作鉴权」）：直接使用公共资源组/稳定进程引用展示和授权终止，不依赖 Windows 包装库。验收：忙/闲统计不同，结束应用无孙进程遗留，不能管理他人任务。各限额执行完成后再展示其控制项。
- [ ] **音频服务与音量管理**（用户态组件、用户态库，前置「最小音频设备接口」、[《原生开发工作站》](./02-workstation.md)的「UNIX 套接字身份与名字」）：用户态提供混音、会话权限与应用音量。验收：两个应用播放可独立停止，服务崩溃可重启，不把应用协议放进驱动。
- [ ] **PID 命名空间**（内核机制、Linux 接口，前置「稳定进程引用与回收」、「挂载命名空间」）：实现层级 PID 视图、信号翻译、局部 PID1 与孤儿回收。验收：内外 PID 查询一致可解释，不能向不可见外层进程发信号，PID1 退出后成员按规则清理。
- [ ] **根目录、bind 与只读挂载**（内核机制、Linux 接口，前置「挂载命名空间」、[《可信命令行》](./01-shell.md)的「公共路径访问检查」）：完成 chroot/pivot_root、bind 和只读标志的 Linux 路径/挂载语义。验收：只读挂载不能写，错误切根可诊断，既有目录 FD/设备句柄按参考规则处理。chroot 本身不承诺安全隔离。
- [ ] **离线 content/headless 目标**（用户态组件，前置「基础运行时与 V8 探针」、[《原生开发工作站》](./02-workstation.md)的「SCM_RIGHTS 描述符传递」）：先在参考 Linux 构建目标，再在 Cinux 执行可信本地页面。验收：JavaScript、DOM 或截图可核对，保存实际进程和缺失接口，不宣称可以公网使用。

### 第 3 步

- [ ] **Vesper 与标准平台连接**（用户态组件、用户态库，前置「进程外窗口最小协议」）：选择并实现 Wayland 接口或明确的平台桥，窗口策略留在合成器。验收：真实外部客户端使用协议，不只在桌面程序里创建新控件。
- [ ] **多进程与崩溃恢复**（用户态组件、内核机制，前置「离线 content/headless 目标」、[《原生开发工作站》](./02-workstation.md)的「普通文件只读共享映射」、「稳定进程引用与回收」）：验证 renderer/共享数据/退出和重启。验收：渲染器崩溃只影响相应页面，关闭多次后页/FD 不持续增长。

### 第 4 步

- [ ] **SDL 软件窗口**（用户态组件、用户态库，前置「Vesper 与标准平台连接」）：移植选定 SDL 显示/输入后端，先软件渲染。验收：独立示例窗口可绘制、收键鼠、变尺寸和退出，为游戏/查看器提供可复用入口。
- [ ] **字体与中文输入**（用户态组件、用户态库，前置「Vesper 与标准平台连接」）：分离字体排版和输入法协议，支持焦点与组合文本。验收：编辑框能输入/删除中文，切换窗口不串输入，不要求内核认识汉字排版。
- [ ] **剪贴板、拖放和文件选择**（用户态组件、用户态库，前置「Vesper 与标准平台连接」、[《可信命令行》](./01-shell.md)的「公共路径访问检查」）：定义数据传递和授权，不默认所有应用可读全局剪贴板。验收：所有者退出、取消选择、无权限文件及跨进程复制均正确处理。
- [ ] **窗口平台后端**（用户态组件、用户态库，前置「多进程与崩溃恢复」、「Vesper 与标准平台连接」）：选择 Wayland 或专用 Ozone 后端，先软件渲染。验收：原生独立窗口能显示/输入/调整大小，不要求先有 GPU 驱动。

### 第 5 步

- [ ] **原生 VNC 查看器**（用户态组件，前置「SDL 软件窗口」、[《多用户服务系统》](./03-services.md)的「HTTPS 与远程访问」）：显示 Ubuntu 等客体桌面，支持输入和重连。验收：在 Cinux 窗口内实际操作，连接受限于可信网络或安全通道，断线不结束桌面。
- [ ] **工具包与会话集成**（用户态组件、用户态库，前置「字体与中文输入」、「剪贴板、拖放和文件选择」、「音频服务与音量管理」）：分别接一个固定 GTK 样本和 Qt 样本，再接启动器、文件管理器与窗口吸附。验收：每个样本独立记录输入/保存/退出结果，不把其中一个成功扩写成全部 GUI 生态兼容。
- [ ] **桌面应用沙箱**（用户态组件、内核机制，前置「权限下降与 seccomp」、「根目录、bind 与只读挂载」、「PID 命名空间」、[《原生开发工作站》](./02-workstation.md)的「基础内存防护」、「剪贴板、拖放和文件选择」）：明确所用 namespace、继承 FD 白名单、drop capabilities/no_new_privs、进程访问限制和 broker 授权。验收：渲染器不能读私有文件、操控同 UID 的外层进程、抓他窗输入或打开任意设备，授权仅开放指定对象。

### 第 6 步

- [ ] **沙箱完整集成**（用户态组件、内核机制，前置「窗口平台后端」、「桌面应用沙箱」、[《多用户服务系统》](./03-services.md)的「可信随机数」、[《多用户服务系统》](./03-services.md)的「信任库与安全更新」）：实现所选版本需要的隔离与 broker 边界。验收：渲染器主动访问私有文件/其他进程/设备时被拒绝，不能靠关闭沙箱过关。

### 第 7 步

- [ ] **公网与日常功能**（用户态组件，前置「沙箱完整集成」、[《多用户服务系统》](./03-services.md)的「HTTPS 与远程访问」、「字体与中文输入」、「剪贴板、拖放和文件选择」）：接证书、中文输入、下载、资料目录和更新路径。验收：固定真实网页及安全负面测试，重启后资料仍在，错误证书不放行。

## 说明

- 内核提供共享内存、描述符和身份传递、事件以及设备访问。合成器、窗口协议、字体、输入法、剪贴板、音频服务都在用户态。
- 浏览器按离线渲染、窗口、多进程、平台后端、沙箱、公网的顺序推进。第一次渲染只访问自带的离线页面，正式上网之前必须验证隔离。

## 通过这一级的检查

- [ ] 两个独立程序同时显示、调整大小、切换焦点，杀掉一个，另一个和桌面都还在。
- [ ] 编辑框能输入和删除中文，切换窗口不串输入。剪贴板所有者退出、取消文件选择、无权限文件和跨进程复制都正确处理。
- [ ] 提交之后缩小、关闭或者重复提交共享缓冲，合成器不越界也不崩溃。
- [ ] 渲染器主动去读私有文件、操控同 UID 的外层进程、抓其他窗口的输入、打开任意设备，全部被拒绝。
- [ ] 固定的真实网页能打开、能输入、能下载，重启后用户资料还在，错误证书不放行。
