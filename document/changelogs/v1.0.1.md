# Cinux v1.0.1 — 🔁 主线切换到重写树
> 本册是 2026-05-25 从旧仓库迁移时的快照，现行有效。

**发布日期：2026-10-31**

从这一版起，Cinux 的主线从 v1 功能树整体切换到「重走」树：带着第一遍的全部后见之明，从 512 字节的 MBR 开始把整个系统从零重搓了一遍（教程 v2 工程，内部叫「重走」）。这不是增量补丁，整棵源码树都换了。v1 功能树永久定格在 `v1.0.0` tag，随时可以 checkout。

## 🔖 这次发版是什么

- 主线切换到重写树。v1 的完整功能树（GCC 自举、SMP、TCP/IP、用户态 GUI 桌面那一套）留在 `v1.0.0` tag，永久可取。
- 重写是在 Cinux-Book 仓里逐站推进的，每一站都有可 checkout 的 tag（`r01` 到 `r35_gui_fin`）。本仓将它作为一个迁移提交（`49ddfb0`）并入，所以本仓的 git log 里没有逐站历史，想逐站考古请移步那边。
- 35 站代码主线已全部完成，正文（教程文字）连载至网络协议栈与网卡驱动，代码先行于文字。

## ✨ Highlights

- 完整弧线按新架构重新长了一遍：实模式 MBR → 保护模式 → 长模式 → 物理内存与按需分页 → 进程与调度 → 系统调用 → ext2 → SMP 双核 → TCP/IP → Vesper 图形桌面 → 在系统里用 GCC 重编整个内核。
- `ping baidu.com` 能通：域名解析进栈，回包真的从外网绕回来。
- 自编译升档。v1.0.0 是在系统里 `gcc hello.c`，这一版是在系统里 `cmake --build build -j` 重新编译整个内核。
- 架构习语整体换代：kernel 一棵树生长，不设 mini 双树。模块按 config（事实旋钮）、announce（公开声明）、impl（实现全藏 .cpp）三件套组织。本机测试与内核共享同一份头文件声明、实现各写各的，全仓禁止 `#ifdef` 分叉。base 收编语义轮子（BitMask、Bitmap、PhysAddr、RingQueue 等），新代码不写裸位运算。产品代码零宏，单文件 500 行上限。QEMU 一律 KVM 硬件穿透，缺席就大声失败，不回退软件模拟。

## 📊 变动规模

`v1.0.0..v1.0.1` 共 107 个提交，净变动 1478 个文件，新增 98,424 行、删除 133,701 行。其中迁移提交 `49ddfb0` 单独改动 1682 个文件（+97,092 / −162,188）。这 107 个提交里约半数是并回子模块时嫁接进主仓的 Cinux-GUI 考古历史（P0 到 P7 的控件、合成器与终端工作）。

## 🕰 v1 树上的收官工作（2026-07 至 2026-08，随本版一并带入）

- NVMe IO 异步化（PR#82）：提交路径从轮询改成信号量阻塞等中断，自旋锁换成互斥锁。
- 调度器任意内核态抢占：任务私有 IRQ 栈、IRQ 退出抢占、系统调用内核段可抢占，根治 NVMe 异步 IO 的跨核卡死，最终支持 preemptible exec 下并发跑 gcc。
- 子模块并回（PR#83）：Cinux-GUI 与 Cinux-Base 并回主仓，CI 去掉 submodule checkout。
- 细节修正与法务：终端 `\b` 只移光标、CSI 光标移动，Error 枚举补 EFAULT/ELOOP/ENOTDIR，仓库立 MIT LICENSE。

## 🧪 验证

tag 所指提交（`49ddfb0`）上 CI 的 host（Release+TSan）、kernel（Debug）、ecosystem（Release）三类任务全绿，ecosystem 段包含 busybox、GCC/G++、完整内核自编译、原生 CMake 构建、ping/DNS/TCP、GUI 的实弹。docs 任务失败，原因是本仓缺 VitePress 站点的 pnpm-lock.yaml（站点内容在 Cinux-Book 仓），与代码和测试无关。

## ⚠️ 限制与已知问题

- 工具链门槛：GCC ≥ 14，CMake ≥ 3.16。
- 跑完整系统必须有可用的 `/dev/kvm`，检测不到会大声失败，不会悄悄降级到软件模拟。
- 第一次构建要联网下载固定版本的 Buildroot 烤一张 1.5 GiB 开发盘，之后走本地缓存复用。
- 正文连载落后于代码：网络协议栈之后的章节（信号与进程组、线程、驱动框架、安全、网络完备、GUI 等）代码已完成，文字还在写。
- UEFI 启动继续推后，本版仍是 BIOS 两阶段引导。

- 在线阅读：https://awesome-embedded-learning-studio.github.io/Cinux-Book/

```sh

cd Cinux-Book
cmake -B build -S .
cmake --build build --target run_gui -j
```
